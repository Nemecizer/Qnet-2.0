# THE WELCOME VIEW

The Welcome view is the start screen. It covers the empty canvas of a blank Untitled tab and offers the quickest ways to a network. It never covers a network you have open.

## WHEN IT SHOWS

- When Qnet starts and there is nothing to restore from last time.
- When you choose Help ▸ Welcome to Qnet or Window ▸ Welcome to Qnet. If the tab in front holds a network, Qnet goes to a blank tab first.

The checkbox Show this at launch, at the bottom of the view and in Settings ▸ General, turns the first of these off.

## WHAT IT OFFERS

- Start with a Tandem Line: two stations in a row, already drawn and ready to Solve.
- New Empty Network: a blank canvas.
- Open…: a network file from this Mac.
- Take the Tour: the [Guided Tour](help:guidedTour). It is offered until you have started the tour once.
- Recent: the networks you opened or saved last.
- Examples: every bundled example with a small diagram and one line about it. Search by name, or filter by kind: Tandem lines, Feedback, Several classes, Finite buffers.

## CLOSING IT

Any of the choices closes the view. So do Close Welcome, Esc (the same as New Empty Network), and picking a drawing tool. While the view is up, the panes under it cannot be clicked or reached with the keyboard.

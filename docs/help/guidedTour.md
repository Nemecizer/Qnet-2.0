# THE GUIDED TOUR

The Guided Tour builds a small network with you, solves it and checks the result. It takes about two minutes. Start it with Help ▸ Guided Tour, or with Take the Tour in [the Welcome view](help:welcomeView).

The tour works in a new Untitled tab of its own, with infinite buffers. It does not touch a network you have open.

## THE EIGHT STEPS

1. Add where customers arrive: a source.
2. Add two stations, each behind its buffer.
3. Add where customers leave: a sink.
4. Link them in a line.
5. Set a service rate.
6. Solve the network.
7. Read the result.
8. Check with another method.

A callout beside the control in question says what to do and why. While you draw, it stays inside the canvas next to the tool the step is about. Its sentences name no device: choose a tool, place a node, select a node. Every step can be done with the pointer or from the keyboard (see [Keyboard and VoiceOver](help:keyboardAndVoiceOver)). A step is done when you have done it on the canvas: the tour sees the network itself and moves on. The two steps that are for reading wait for Next.

In step 5 the tour waits for a rate the line can keep up with. If you make a station slower than customers arrive, the callout says so and suggests a rate, because such a network has no steady state to solve.

## THE BUTTONS

- Show Me does the step for you, with the same tools and commands you would use. Everything it does can be undone.
- Back and Next move between steps. Skip goes on without doing the step.
- End Tour, or Esc, ends the tour. The tab and what you built stay.

## COMING BACK

Help ▸ Guided Tour picks the tour up at the first step still to do, in its own tab. After the last step, or once that tab is closed, it starts afresh.

The tour ends with a card that gives the verdict of the two methods and three things to try next: a What-If Sweep, an example, and the Method Chooser.

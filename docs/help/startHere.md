# START HERE

Qnet draws queueing networks and computes how they behave: how busy each station is, how many customers wait there, and how long they stay. This page is the shortest path from an empty window to an answer you can trust.

## THREE STEPS

1. Get a network. Draw one with the tools (source, station, buffer, sink, then links between them), or open a finished one with File ▸ Open Example…. The button below opens a small one.
2. Press Solve (⌘↩). Qnet picks the best method for the network and runs it.
3. Read the answer. The Results pane shows the numbers, and the canvas shows each station's value beside it. Choose Run ▸ Check with Another Method to see how sure to be; the Agreement view has a button for it that names the method.
